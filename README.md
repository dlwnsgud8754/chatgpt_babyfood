# 아율의 한입 — 밥솥 이유식 식단·레시피·기록

이전 React/Vite 앱을 제거하고 사용자 제공 두 표를 기반으로 새로 만든 **단일 HTML 앱**입니다. 저장소 자체와 이전 커밋 이력은 유지했습니다.

## 설치 없이 실행

1. GitHub에서 `index.html`을 열고 **Download raw file** 버튼으로 다운로드합니다.
2. 파일을 Chrome 또는 Edge로 엽니다.

Git, Node.js, npm 설치가 필요하지 않습니다. 스타일·아이콘·스크립트·초기 데이터가 모두 HTML 안에 포함되어 외부 요청 없이 사용할 수 있습니다. 홈 화면 PWA 설치는 이 로컬 HTML 버전에서 제공하지 않습니다.

선택 날짜의 초기값은 표의 첫 조리일인 **2026-10-14**입니다. ‘오늘’ 버튼으로 현재 날짜로 이동할 수 있습니다.

## 두 표 반영

- 첫 조리 및 A·B·C: 총 4개 밥솥 레시피
- 생곡물/불린 곡물, 단백질, 채소 합계, 육수·배죽, 소분 계획·최종량·NEW·조리 메모
- 2026-10-12~31 주간표와 입력된 오전·오후 식단·새 재료·메모
- 통과 재료 9가지, 청경채의 ‘설사’ 메모
- 밀가루·당근은 새 재료 계획이며 통과 결과 미확인
- B·C·D 소고기 베이스 필수, 원본 주간 기호 패턴 및 준비 요일

빈 중량은 임의 추정하지 않았습니다. 원본의 0 합계는 미입력 행으로 처리했습니다. D·E·F 레시피는 재료 정보가 없어 생성하지 않았습니다. 레시피의 ‘중기’는 앱 초기 분류이며 변경할 수 있습니다. 빨간색 서식이 전달되지 않았으므로 통과 목록·NEW·새 재료 칸을 기준으로 표시했습니다.

### 원본에서 확인이 필요한 차이

- 첫 표의 10/14 요일은 ‘화’이고 두 번째 표는 2026-10-14 ‘수’입니다. 연도가 있는 두 번째 표의 날짜를 사용합니다.
- 당근은 조리표 10/17 NEW, 주간표 10/18 새 재료입니다. 실제 테스트 날짜는 확인이 필요합니다.
- 첫 레시피 원본 재료총합은 448.1g입니다. 불린 쌀 51g + 소고기 50g + 채소 110g + 육수 240g의 합계는 451g입니다. 원본 합계와 앱 계산값을 구분합니다.
- 청경채는 통과 목록에 있으나 ‘설사’ 메모도 있습니다. 메모만으로 알레르기를 확정하거나 상태를 바꾸지 않았습니다.

## 기능

- 데일리·주간 식단 편집, 직접 메뉴 입력, NEW·메모 기록
- 밥솥 레시피 CRUD, 단계별 필터, 재료 검색
- 불리기 전/후 중량 기준 재료 합계, 실제 최종량에 따른 소분 개수·여유분 계산
- 생곡물 합계 × 배죽 배수의 육수 입력 보조 기능 (실제 중량 우선)
- 제공량·섭취량·새 재료·반응·메모 기록 및 편집/삭제
- 통과·테스트 중·미확인·주의 재료 상태 관리
- 선택일/주간 식단의 레시피별 조리 배치를 묶은 장보기, 직접 추가·구매 체크
- JSON 백업·검증 후 복원, 주간 식단/식사 기록 CSV, 주간 인쇄
- 반응형 화면, 외부 라이브러리 없는 순수 HTML/CSS/JavaScript

같은 레시피의 반복 끼니는 장보기에서 한 조리 배치로 묶으며 기존 목록에 있는 재료는 다시 추가하지 않습니다. 채소별 개별 중량이 없을 때는 원본 합계 그대로 표시합니다. 실제 조리 횟수가 다르면 목록의 직접 추가 기능을 사용하세요.

## 기록 저장과 백업

현재 브라우저의 `localStorage`(`ayul-babyfood-v1`)에 저장합니다. 서버·계정 동기화가 없습니다. 파일 위치, 기기 또는 브라우저를 바꾸거나 브라우저 데이터를 삭제하면 기존 기록이 사라지거나 보이지 않을 수 있습니다. 정기적으로 설정 → JSON 백업을 다운로드하세요. 다른 기기에서는 동일 HTML 앱에서 백업을 불러오면 됩니다. 이전 앱의 저장 키는 건드리지 않으며 자동 이관하지 않습니다.

백업 불러오기는 현재 데이터를 교체하므로 먼저 현재 데이터를 다운로드하고, 형식·값·파일 크기를 검사합니다. 중요한 기록은 별도로 보관하세요.

## 검증

Chromium에서 외부 요청을 차단한 상태로 초기 식단, 390px 모바일 레이아웃, 주간 7일 표시, 식사량·알레르기 기록 및 새로고침 유지, 장보기 구매 상태 유지, 레시피 중량 계산·B/C/D 규칙·메뉴 지정, 재료 메모·입력 문자열 이스케이프, 프로필, JSON 백업·복원 및 잘못된 백업 거부를 확인했습니다. 1440px 화면도 확인했습니다.

클라우드 브라우저 정책이 `file://` 직접 열기를 차단하여 HTML 내용을 브라우저 테스트 경로로 제공해 검증했습니다. 실제 Windows 로컬 파일 열기와 Android에서는 별도 확인이 필요합니다.

이 앱은 의료기기가 아닙니다. 원본 만능찜 시간은 당시 조리 기록이며 모든 밥솥의 권장 시간이 아닙니다. 아기의 발달·기존 알레르기 및 의료진 조언에 맞춰 조절하세요.
