# 한입 — 이유식 모바일 PWA

React + Vite로 만든 한국어 이유식 앱입니다. 데이터는 현재 브라우저의 localStorage에 저장됩니다. 계정, 서버 동기화는 없으며 브라우저 데이터를 삭제하면 기록도 삭제됩니다.

## 설치 없이 HTML 파일로 실행

저장소의 `hanip.html`을 다운로드한 뒤 Chrome이나 Edge로 여세요. Node.js, npm, Git 설치가 필요하지 않습니다. 스타일과 실행 코드가 모두 포함되어 외부 다운로드 없이 동작합니다. 로컬 파일 저장소 정책은 브라우저마다 다르며 파일 위치나 브라우저를 바꾸면 기존 기록이 보이지 않을 수 있습니다.

HTML 버전은 홈 화면 설치를 제공하지 않습니다. PWA 설치는 기존 HTTPS 배포 버전을 사용하세요.

소스 수정 후 HTML 재생성: `npm run build:html`. 생성된 HTML의 식단·레시피·기록·장보기와 저장 유지, 외부 요청이 없음을 Chromium에서 검증했습니다. 클라우드 브라우저 정책으로 `file://` 직접 열기는 검증하지 못했습니다.

## 개발

```sh
npm ci
npm run dev
```

## 배포 / PWA 확인

```sh
npm run build
npm run preview -- --port 4173
```

`dist` 폴더를 HTTPS를 제공하는 정적 호스팅에 배포하세요. SPA의 모든 경로는 index.html로 연결하세요. 안드로이드 Chrome에서 접속하고 메뉴 → 앱 설치 / 홈 화면에 추가를 선택합니다. 실제 기기에서의 설치는 배포 후 확인해야 합니다.

빌드 시 서비스 워커가 전체 앱과 설치 아이콘을 캐시하도록 생성됩니다. 최초 온라인 접속과 캐시 완료 후에는 오프라인에서도 실행됩니다. 개발 서버에서는 오프라인 캐시를 제공하지 않으며, PWA 검증은 프로덕션 빌드로 진행하세요.

## 기능

- 데일리·7일 식단 계획, 날짜 및 끼니별 메뉴 선택
- 초기·중기·후기·완료기 레시피와 즐겨찾기
- 날짜별 식사량, 새 재료, 알레르기 반응 및 메모 기록
- 식단에서 장보기 재료 추출, 직접 추가, 구매 체크 및 삭제
- 아기 이름·월령 설정
- 모바일 하단 탐색, 홈 화면 설치 안내, 오프라인 지원

레시피의 월령과 양은 참고 정보입니다. 아기의 발달, 기존 알레르기 및 의료진의 조언에 맞춰 조절하세요. 레시피는 의료 전문가의 검토를 거치지 않았습니다.

## 검증

프로덕션 빌드 및 Chromium 390px 화면에서 식단 추가, 식사량·알레르기 저장, 장보기 생성·구매 상태 유지, 새로고침 후 기록 유지, 오프라인 새로고침 및 가로 넘침 여부를 확인했습니다. 실제 안드로이드 설치는 미검증입니다.
